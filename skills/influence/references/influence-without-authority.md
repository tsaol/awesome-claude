# Influence Without Authority：要点

Allan R. Cohen、David L. Bradford，1990 年首版，2017 年第 3 版（Wiley）。繁体中文版《沒權力也能有影響力》（臉譜）；简体旧版《影响力：如何展示非权力的领导魅力》。

> **AI 整理，待核对。** 这份摘要是 AI 根据对这本书的了解写的，不是原书摘抄，也还没有逐条对照原书核实。货币的分类和具体名称以原书为准，发现不一致请改这里。

## 核心想法：交换

组织里很多事要靠没有上下级关系的人来完成。人愿意帮你，是因为得到了**他看重的东西**。书里把这些东西叫作"**货币**"（currencies）。影响力就是**用对方看重的货币，换你需要的帮助**。交换不一定当场完成，也可以先存进"关系账户"。

## 影响力模型的六步

1. **假设每个人都是潜在的盟友。** 别先把对方当成"难搞的人"。先想：什么样的压力会让一个讲道理的人这样做？
2. **说清自己的目标和优先级。** 哪些必须要，哪些可以让。别把个人情绪混进目标。
3. **了解对方的世界。** 他的工作、考核、老板、压力、担心。通常是这些力量在决定他的行为，而不是他的性格。
4. **找出相关的货币：他看重什么，你有什么。** 很多人以为自己"没什么可给的"，其实信息、帮忙、认可都是货币。
5. **处理关系。** 你们的关系怎么样？他喜欢怎么被沟通？关系越好，交换越容易；关系透支时，先修关系。
6. **通过交换产生影响。** 提出具体的请求，说清对他的好处，兑现你给的东西。

## 常见的货币（五类）

| 类 | 例子 |
|---|---|
| **激励**（愿景、意义） | 参与一件重要的事、把事情做到最好、做正确的事 |
| **任务** | 新的资源、有挑战的工作、帮他解决难题、组织上的支持、快速响应、信息 |
| **地位** | 被认可、被看见（比如在他老板面前）、名声、进入核心圈子、人脉 |
| **关系** | 被理解、被接纳、被当成自己人、个人的支持 |
| **个人** | 感谢、参与感和主人翁感、符合他对自己的看法、省事 |

## 几条实用的提醒

- 货币的价值由**对方**决定，不是由你决定。你觉得很值钱的东西，他可能不在乎。
- 想不出对方要什么时，**直接问**，或者问和他走得近的人。
- 对上级也一样：老板也有压力和货币，"向上影响"同样要从他的世界出发。
- 请求要小而具体；事后感谢要具体，最好让他的老板看到。
- 关系要在需要之前就建立。平时多存款，急的时候才取得出来。
- 和操纵的区别：交换是公开的、对方知道并且愿意的；一旦对方觉得被利用，关系账户会一下子清零。
