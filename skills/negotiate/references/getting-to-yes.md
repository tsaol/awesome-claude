# Getting to Yes：要点

Roger Fisher、William Ury（后来的版本加入 Bruce Patton），哈佛谈判项目，1981 年首版。中文版《谈判力》，另有译本《哈佛经典谈判术》。

## 判断协议好坏的三个标准

明智（尽量满足双方合理的利益）、高效、不伤关系。

## 三种谈判方式

| 软式 | 硬式 | 原则式 |
|---|---|---|
| 对方是朋友 | 对方是敌人 | 大家一起解决问题 |
| 为了关系让步 | 把让步当成关系的条件 | 对人软，对事硬 |
| 亮出底线 | 隐藏、误导底线 | 不设死底线，想清楚 BATNA |
| 屈服于压力 | 施加压力 | 只屈服于道理 |

每一步都同时在谈两件事：内容本身，和"这场谈判按什么规则玩"。

## 原则一：把人和问题分开

- 人的问题分三类：**看法、情绪、沟通**。
- 看法：站到对方的位置看；让对方参与想方案，方案就是"他的"；给对方留面子。
- 情绪：承认情绪，让对方发泄，不对发泄做反应。
- 沟通：主动倾听并复述；说"我觉得"，不说"你总是"。
- 关系要在谈之前建立。从"面对面"变成"肩并肩"一起看问题。

## 原则二：关注利益，不是立场

- 立场是他决定要的东西，利益是让他这样决定的原因。
- 找利益：对每个立场问"为什么"；对你要他做的决定问"他为什么不愿意"。
- 最底层的利益：安全感、经济利益、归属感、被认可、自主权。
- 先讲理由和利益，最后讲方案；多谈未来，少谈过去。
- 对自己的利益坚定，对自己的方案灵活。

## 原则三：创造双赢的选项

- 四个障碍：太早下判断、只找一个答案、以为蛋糕是固定的、"他的问题他自己解决"。
- 先想后选：头脑风暴时不批评，记下来，再挑最好的几个改进。
- 扩大选项：换不同专业的视角；准备"小一点"的协议；想想怎么"把蛋糕做大"。
- **利用差别**：利益、看法、对时间的看重、对未来的预测、对风险的态度不同，都可以拿来交换。
- 让对方容易做决定：挑一个具体的人看他的处境；找先例；替他写"他会被怎么批评"和"他可以怎么解释"。

## 原则四：坚持客观标准

- 标准要独立于双方的意愿：市场价格、先例、行业惯例、专家意见、科学数据。
- 也可以用公平的程序：一个切一个挑、轮流、抽签、第三方决定。
- 把每个问题变成"一起找标准"；问对方"这个方案的依据是什么"；只对道理让步，不对压力让步。

## 对方更强大：BATNA

- BATNA = 谈不成时你最好的退路。
- 死底线太僵，会让你错过好协议或接受坏协议；用 BATNA 来衡量每个方案。
- 做 BATNA：列出谈不成时能做的事 → 把好的几个变成能执行的方案 → 选最好的一个。
- BATNA 强、或者对方以为你没有退路时，可以说出来；比对方想的弱时，别说。
- 估计对方的 BATNA；他高估了，就帮他看清现实。
- 双方 BATNA 都很好时，不达成协议可能是最好的结果。

## 对方不按规矩来：谈判柔术

- 不攻击对方的立场，把它当一个选项，找背后的利益。
- 不为自己的方案辩护，请对方批评和提建议。
- 人身攻击时，先听，再把攻击转成问题本身。
- 多问问题，少下结论；用沉默。
- 一个文本法：第三方起草一份方案，双方一起改，最后一起接受或拒绝。

## 对方耍花招

- 认出来 → 说出来 → 拿出来谈"规则本身"。
- 欺骗：不确定就别轻信，把保障写进协议。
- 心理战：点破就会减弱。不威胁，用"提醒后果"。
- 极端要求：点出来，它会损害对方的可信度。
- "要么接受要么走人"：说清谈不成他会失去什么，给他一个有面子的台阶。
